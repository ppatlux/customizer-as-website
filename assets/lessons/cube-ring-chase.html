Ring Chase

The cube's top is a ring of 12 LEDs with a single button. A blue light chases around the ring; one fixed LED glows red as the target. Press the button at the exact moment the blue light lands on the red one — hit it and you level up and the chase gets faster. It never ends: 16 levels, then it wraps and resets.

⏱ 25–40 min 🐍 MicroPython 🎯 Timing game 1 button

# ringchase.py, top of file
button_pin = 26
pixel_pin  = 4
no_pixels  = 12
pixels = NeoPixel(Pin(pixel_pin), no_pixels)
button = Pin(button_pin, Pin.IN, Pin.PULL_UP)   # pressed = value() 0
Just one button and one ring — no buzzer (the file imports PWM but never uses it). The whole game is about when you press, not which button.

2 · Two positions on the ring

Everything is two numbers, both 0–11:

  • counter — where the blue chaser is right now.
  • randomNumber — where the red target sits (picked once at start, then again after every press).

A catch is simply counter == randomNumber at the instant you press.

3 · The chase loop

gameLoop() walks counter around the ring. At each LED it lights blue, waits speed milliseconds, checks the button, clears blue, and re-draws the red target so it stays visible as the chaser passes over it:

for count in range(no_pixels):
    pixels[counter] = (0, 0, 100)      # blue chaser on
    pixels.write()
    time.sleep_ms(speed)               # the whole difficulty knob
    checkStatus()                      # look at the button
    pixels[counter] = (0, 0, 0)        # blue chaser off
    counter += 1
    pixels[randomNumber] = (255, 0, 0) # keep the red target lit
    pixels.write()

There's no separate "input thread" — the button is polled once per LED step, right in the middle of the animation. That's the core pattern for a small microcontroller: one loop does the drawing and the input.

4 · Catch, miss, level up

checkStatus() is where a press is judged:

def checkStatus():
    if button.value() == 0:
        while button.value() == 0:      # wait until it's released
            time.sleep_us(100)
        if counter == randomNumber:     # chaser is on the target
            turnOnAll(30, 150, 30)      # whole ring flashes green
            speed -= 10                 # faster next level
            level += 1
            showLevel()
        else:
            turnOnAll(50, 0, 0)         # whole ring blinks red
        turnOff()
        randomNumber = random_int(0, no_pixels - 1)   # new target
Notice a miss just flashes red and moves on — there's no "game over". Ring Chase is a score chase, not a lives game. Adding a real fail state is challenge 3 below.

5 · Levels and the wrap

showLevel() draws the current level as a little green progress bar (one lit LED per level), blinks, then clears. It also holds the difficulty ceiling:

if level > 16:
    level = 1
    speed = 180        # wrap back to the start, easy again

So speed ramps 180 ms → 20 ms over 16 levels (speed -= 10 each time), then resets. That's the entire progression curve, in two lines.

Try it

  • EASYStart easier or harder: change speed = 180 and the speed -= 10 step.
  • EASYRecolour the chaser and target (the (0,0,100) and (255,0,0) tuples).
  • MEDAdd a real game over: keep a lives count, subtract one on a miss, stop the while True loop at zero.
  • MEDMake the chaser reverse direction each level (counter -= 1, wrap with % no_pixels).
  • HARDAdd the buzzer that's already imported: a rising blip on a catch, a low buzz on a miss.
  • HARDTwo targets lit at once for a "double" round every 4 levels.
